# CoreMC static launch landing page

This is an original, dependency-free responsive site you can publish on GitHub Pages, Vercel or basic web hosting. No store or paid checkout is active. The hero includes a **CSS concept illustration**, not a misleading screenshot of a completed Minecraft world.

## Deployment
1. Edit `config.js` with verified public Java IP and Discord URL.
2. Preview by opening `index.html` locally or serving the folder as a static root.
3. Publish the **contents of this folder**, not the plugin source, to your static host.
4. Add real screenshots once the lobby is built and review accessibility on mobile.
5. Before opening a paid shop, publish specific prices and contents, contact method, purchase/refund history arrangements, privacy policy and accurate brand disclaimer. The current page does not solicit payments.

User data: this static site stores no forms, trackers or cookies. The server itself requires separate rules/privacy information before public opening.

Visual design is intentionally restrained (grid lines, cyan navigation, typography, five simple districts) instead of glassmorphism, fake play statistics or empty oversized cards.
